# Sticky

## Overview

Makes an element stick to the top or bottom of the screen

```html
<div class="b-sticky"></div>
```

## Modifiers

### Position

Sets the position.

| Name                  | Description                     |
|-----------------------|---------------------------------|
| `c-sticky--top`       | Sets the position to the top    |
| `c-sticky--bottom`    | Sets the position to the bottom |
