# Link-Block ​

Padded link pattern for navigation and tab-UI.

```
<div class="o-cluster u-color-neutral">
	<a class="c-link-block b-tint" href="#">Tab 1</a>
	<a class="c-link-block b-tint" href="#">Tab 2</a>
	<a class="c-link-block b-tint" href="#">Tab 3</a>
</div>
```

## Modifiers

### Spacing ​

Applies inline padding around the link.

```
<div class="o-cluster u-color-neutral">
	<a class="c-link-block c-link-block--spacing-sm b-press-tint" href="#">Tab 1</a>
	<a class="c-link-block c-link-block--spacing-sm b-press-tint" href="#">Tab 2</a>
	<a class="c-link-block c-link-block--spacing-sm b-press-tint" href="#">Tab 3</a>
</div>
```
