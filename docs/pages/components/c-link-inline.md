# Link-Inline ​

Inline link pattern for navigation.

```
<div class="o-cluster">
	<a class="c-link-inline" href="#">Link 1</a>
	<a class="c-link-inline" href="#">Link 2</a>
	<a class="c-link-inline" href="#">Link 3</a>				
	<a class="c-link-inline" href="#">Link 4</a>		
</div>
```

## Modifiers

### Quiet

Stops a text decoration line from being added on interaction.

```
<a class="c-link-inline c-link-inline--quiet" href="#">Link</a>
```
