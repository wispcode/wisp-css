# Table Wrapper

Makes a table scrollable on small screens.

```
<div class="c-table-wrapper" style="max-width: 400px;">
	<table class="c-table c-table--border-rows">
		<thead>
			<tr>
				<th>Head 1</th>
				<th>Head 2</th>
				<th>Head 3</th>
				<th>Head 4</th>
				<th>Head 5</th>
				<th>Head 6</th>
			</tr>
		</thead>
		<tbody>
			<tr>
				<td>Cell 1</td>
				<td>Cell 2</td>
				<td>Cell 3</td>
				<td>Cell 4</td>
				<td>Cell 5</td>
				<td>Cell 6</td>
			</tr>
			<tr>
				<td>Cell 1</td>
				<td>Cell 2</td>
				<td>Cell 3</td>
				<td>Cell 4</td>
				<td>Cell 5</td>
				<td>Cell 6</td>
			</tr>
		</tbody>
	</table>
</div>
```
