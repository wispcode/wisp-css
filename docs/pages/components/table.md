# Table

Creates a table for displaying data.
  
	<table class="c-table">
		<thead>
			<tr>
				<th>Head 1</th>
				<th>Head 2</th>
				<th>Head 3</th>
			</tr>
		</thead>
		<tbody>
			<tr>
				<td>Head 1</td>
				<td>Head 2</td>
				<td>Head 3</td>
			</tr>
			<tr>
				<td>Head 1</td>
				<td>Head 2</td>
				<td>Head 3</td>
			</tr>
		</tbody>
	</table>

## Modifiers

### Border Cells

			<tr>
				<th>Head 1</th>
				<th>Head 2</th>
				<th>Head 3</th>
			</tr>
		</thead>
		<tbody>
			<tr>
				<td>Head 1</td>
				<td>Head 2</td>

			<tr>
				<td>Head 1</td>

		</tbody>
	</table>

## Notes

### Scroll

Use the `scroll` behavior to make the table scrollable on small screens.

	<div class="b-scroll" style="max-width: 400px;">
		<div class="b-scroll__content">
			<table class="c-table c-table--border-rows">
				<thead>
					<tr>
						<th>Head 1</th>
						<th>Head 2</th>
						<th>Head 3</th>
						<th>Head 4</th>
						<th>Head 5</th>
						<th>Head 6</th>
					</tr>
				</thead>
				<tbody>
					<tr>
						<td>Cell 1</td>
