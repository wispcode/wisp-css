# Container

Constrains content width and centers it.
  
	<div class="o-container">
		<h2>About Us</h2>	
	</div>

<div class="u-vite-preview">
	<div class="o-container u-color-neutral" style="padding-inline: 1rem">
		<p>Normal</p>
	</div>
</div>
