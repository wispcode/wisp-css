## Modifiers

### Spacing

Applies inline padding around the link.

		<a class="o-link-block o-link-block--spacing-sm b-tint" href="#">Tab 2</a>
		<a class="o-link-block o-link-block--spacing-sm b-tint" href="#">Tab 3</a>
