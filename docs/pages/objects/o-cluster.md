# Cluster

Arranges items horizontally using consistent spacing.

```
<div class="o-cluster">
	<a class="c-link-inline" href="#">Link 1</a>
	<a class="c-link-inline" href="#">Link 2</a>
	<a class="c-link-inline" href="#">Link 3</a>				
	<a class="c-link-inline" href="#">Link 4</a>		
</div>
```

		<a class="c-link-inline" href="#">Link 1</a>
		<a class="c-link-inline" href="#">Link 2</a>
		<a class="c-link-inline" href="#">Link 3</a>				
		<a class="c-link-inline" href="#">Link 4</a>		
	</div>
</div>

## Modifiers

### Responsive

Stacks the items on smaller screens.

```
<div class="o-cluster o-cluster--responsive">
	<a class="c-link-inline" href="#">Link 1</a>
	<a class="c-link-inline" href="#">Link 2</a>
	<a class="c-link-inline" href="#">Link 3</a>				
	<a class="c-link-inline" href="#">Link 4</a>		
</div>
```
