# Container

Arranges items horizontally using consistent spacing.

```
<div class="o-container">
	<h2>About Us</h2>
</div>
```

<div class="c-doc-preview">
	<div class="o-container u-color-neutral"  style="padding-inline:1rem;">
		Container
	</div>
</div>

## Modifiers

### Spacing

Applies horizontal padding.

```
<div class="o-container o-container--spacing-xs">
	Extra-small
</div>
```
