# Media

Aligns an image next to content.

```
<div class="o-media">
	<div class="o-media__image">
		<img src="https://placeholdit.com/64x64/1d4ed8/ffffff" alt="">
	</div>
	<div class="o-media__content">
		Lorem ipsum dolor sit amet, consectetur adipiscing elit.
	</div>
</div>
```
