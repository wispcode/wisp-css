# Sticky  Position

Makes an element stick to the top of the screen.

```
<div class="u-position-sticky">
	<div class="c-box u-color-primary">Sticky Header</div>
</div>

<p>Paragraph</p>
<p>Paragraph</p>
<p>Paragraph</p>
<p>Paragraph</p>
<p>Paragraph</p>
```
