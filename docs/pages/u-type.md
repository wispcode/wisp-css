# Type

Sets a font-size, font-weight and line-height.

```
<p class="u-type-5xl">Heading</p>
<p class="u-type-4xl">Heading</p>
<p class="u-type-3xl">Heading</p>
<p class="u-type-2xl">Heading</p>
<p class="u-type-xl">Heading</p>
<p class="u-type-lg">Heading</p>
<p class="u-type-md">Heading</p>
<p class="u-type-sm">Heading</p>
```
