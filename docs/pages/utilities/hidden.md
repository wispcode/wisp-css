# Hidden

Hides an element below a breakpoint, reverting to its natural display value above it.

	<p class="c-box u-hidden-sm u-color-neutral"> 
		Hidden for small breakpoints.
	</p>

	<p class="c-box u-hidden-md u-color-neutral"> 
		Hidden for medium breakpoints.
	</p>
