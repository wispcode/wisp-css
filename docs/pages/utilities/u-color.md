# Color

Sets a background and text color.

```
<p class="c-box u-color-primary">Primary</p>
<p class="c-box u-color-secondary">Secondary</p>
<p class="c-box u-color-neutral">Neutral</p>
<p class="c-box u-color-surface">Surface</p>
```
