# Hidden Below

Hides an element when it's below the specified breakpoint.

```
<p class="c-box u-hidden-below-md u-color-neutral">
	Hidden below medium breakpoints.
</p>

<p class="c-box u-hidden-below-lg u-color-neutral">
	Hidden below large breakpoints.
</p>
```
