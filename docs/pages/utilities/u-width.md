# Width

Show the width of an element.

```
<p><input class="c-input u-width-xs" type="text"></p>
<p><input class="c-input u-width-sm" type="text"></p>
<p><input class="c-input u-width-md" type="text"></p>
<p><input class="c-input u-width-lg" type="text"></p>
<p><input class="c-input u-width-xl" type="text"></p>
<p><input class="c-input u-width-full" type="text"></p>
```
